How to connect this page to a Google Sheet (one-time setup)
  1. Create a new Google Sheet (any name is fine — the page will manage a tab called Profiles inside it).
  2. In the Sheet, open Extensions → Apps Script.
  3. Delete anything in the editor and paste in the Apps Script code provided alongside this file. Fill in CLIENT_ID and ALLOWED_EMAILS at the top with your family's Google account emails, then save.
  4. Click Deploy → New deployment, choose type Web app. Set "Execute as" to Me and "Who has access" to Anyone, then click Deploy and authorize it. (Access is still restricted — the script itself checks the signed-in email against your allow-list on every request.)
  5. Copy the Web app URL it gives you and paste it into the box below.
  6. In Google Cloud Console → Credentials, create an OAuth Client ID (type "Web application"), add this page's URL under "Authorized JavaScript origins," and paste that Client ID into the GOOGLE_CLIENT_ID constant near the bottom of this file's script.
  7. Reload the page, sign in with an allow-listed Google account, then use Load from Sheet / Save to Sheet as normal.
